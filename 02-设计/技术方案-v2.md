# 公司管理平台 v2.0 技术方案

## 版本目标

完善任务、待办的新增改查功能，提升页面交互体验。

---

## 功能清单（P0）

### 任务模块增强
1. **删除任务** — 后端 DELETE /api/tasks/:id + 前端确认对话框
2. **编辑任务** — 后端 PUT /api/tasks/:id（全字段更新）+ 前端编辑 Modal
3. **任务详情** — 点击任务卡片弹出详情 Drawer/Modal，展示完整信息
4. **状态拖拽** — 看板模式下拖拽任务卡片切换状态列（todo→in-progress→review→completed）
5. **批量操作** — 列表模式下多选任务批量删除/变更状态
6. **API 完善** — PUT 全字段更新、DELETE 删除、PATCH 保持状态更新

### 待办模块（新增）
1. **独立待办表** — `todos` 表（轻量级个人待办，与任务区分）
2. **后端 CRUD** — GET / POST / PUT / PATCH / DELETE /api/todos
3. **前端页面** — 新增 /todos 路由，待办列表 + 创建/编辑/删除
4. **导航入口** — 侧边栏新增「待办」导航项

### 交互增强
1. **Toast 通知** — 成功/失败/警告提示，替代 alert/控制台
2. **确认对话框** — 删除操作二次确认
3. **无刷新更新** — 增删改后自动刷新列表，不重新加载页面
4. **加载状态** — 按钮/表单提交时禁用 + loading 指示器
5. **空状态优化** — 各页面空状态插画 + 引导文案

---

## 数据库 Schema 变更

### 新增 todos 表
```sql
CREATE TABLE IF NOT EXISTS todos (
  id          TEXT PRIMARY KEY,
  title       TEXT NOT NULL,
  completed   INTEGER NOT NULL DEFAULT 0,  -- 0=未完成, 1=已完成
  priority    TEXT NOT NULL DEFAULT 'medium' CHECK(priority IN ('high','medium','low')),
  due_date    TEXT,
  assignee_id TEXT,
  assignee_name TEXT,
  assignee_avatar TEXT,
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL
);
```

### 现有表兼容
- tasks 表不变，已有 completed_at 字段用于记录完成时间
- 新增 todo_count 到 departments 统计（可选，v2.1）

## 前端架构

### 新增组件
1. `Toast.tsx` — 全局 Toast 通知组件
2. `ConfirmDialog.tsx` — 确认对话框组件
3. `TaskDetailDrawer.tsx` — 任务详情抽屉
4. `TodoPage.tsx` — 待办页面

### 修改组件
1. `CreateModal.tsx` — 支持「编辑模式」（传入初始值）
2. `Tasks.tsx` — 增加删除、编辑、详情、拖拽
3. `Sidebar.tsx` — 新增「待办」导航项
4. `api/index.ts` — 新增 todos API、tasks.delete/tasks.update

### 交互设计
- 看板拖拽：使用 `@dnd-kit/core` 或原生 HTML5 Drag API（轻量优先，用原生）
- Toast：使用 framer-motion 动画 + 自动关闭
- 确认对话框：Modal 覆盖层 + 按钮

## 风险分析

| 风险 | 等级 | 应对措施 |
|------|------|----------|
| 拖拽实现复杂 | 中 | 用原生 HTML5 Drag API，不引入新依赖 |

- 保持现有技术栈（React + Vite + Tailwind + SQLite）
