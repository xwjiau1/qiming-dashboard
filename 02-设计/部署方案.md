## 部署步骤

### Step 1: 后端服务启动

```bash
cd /root/.openclaw/workspace/tech/projects/company-platform/03-源码

# 开发模式启动
npx tsx src/backend/index.ts

# 生产模式（使用 systemd）
systemctl start company-platform
systemctl enable company-platform
```

**服务验证:**
```bash
curl -s http://localhost:3001/api/health
# {"success":true,"data":{"version":"1.0.0","status":"ok"}}
```

### Step 2: Cloudflare 登录授权

```bash
cloudflared tunnel login
```

执行后会显示浏览器授权 URL：
```
https://dash.cloudflare.com/argotunnel?callback=...
```

**操作:**
1. 复制 URL 到浏览器打开
2. 登录 Cloudflare 账号（管理 `metanoia-labs.com`）
3. 点击授权按钮
4. 看到 `Success` 页面即为完成

授权完成后，`~/.cloudflared/cert.pem` 证书文件生成。

### Step 3: 创建 Tunnel

```bash
cloudflared tunnel create company-platform
```

**输出示例:**
```
Tunnel credentials written to ~/.cloudflared/20f896af-aa35-4abc-9f6c-6a52d76cce2f.json
Created tunnel company-platform with id 20f896af-aa35-4abc-9f6c-6a52d76cce2f
```

**记录 Tunnel ID:** `20f896af-aa35-4abc-9f6c-6a52d76cce2f`

### Step 4: 绑定 DNS 子域名

```bash
cloudflared tunnel route dns --overwrite-dns company-platform platform.metanoia-labs.com
```

**输出:**
```
Added CNAME platform.metanoia-labs.com which will route to this tunnel
```

### Step 5: 创建配置文件

```bash
cat > /etc/cloudflared/config.yml << 'EOF'
tunnel: 20f896af-aa35-4abc-9f6c-6a52d76cce2f
credentials-file: /etc/cloudflared/tunnel.json

ingress:
  - hostname: platform.metanoia-labs.com
    service: http://localhost:3001
  - service: http_status:404
EOF
```

**复制凭证文件:**
```bash
cp /root/.cloudflared/20f896af-aa35-4abc-9f6c-6a52d76cce2f.json /etc/cloudflared/tunnel.json
```

### Step 6: 安装并启动系统服务

```bash
# 安装 systemd 服务
cloudflared service install

# 启动服务
systemctl start cloudflared
systemctl enable cloudflared

# 检查状态
systemctl status cloudflared
```

**服务状态:**
```
● cloudflared.service - cloudflared
     Active: active (running)
     Main PID: 1565873 (cloudflared)
```

### Step 7: 验证部署

```bash
# DNS 解析验证
host platform.metanoia-labs.com
# platform.metanoia-labs.com has address 104.21.54.28
# platform.metanoia-labs.com has address 172.67.222.229

# HTTPS 健康检查
curl -s https://platform.metanoia-labs.com/api/health
# {"success":true,"data":{"version":"1.0.0","status":"ok"}}

# 前端页面访问
curl -s https://platform.metanoia-labs.com/ | grep -o 'title[^>]*'
```

## 系统服务配置

### 1. company-platform.service (后端服务)

```ini
[Unit]
Description=启明科技·公司管理平台
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/.openclaw/workspace/tech/projects/company-platform/03-源码
ExecStart=/usr/bin/npx tsx src/backend/index.ts
Restart=always
RestartSec=5
Environment=NODE_ENV=production
Environment=PORT=3001

[Install]
WantedBy=multi-user.target
```

### 2. cloudflared.service (Cloudflare Tunnel)

```ini
[Unit]
Description=cloudflared
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/cloudflared --no-autoupdate --config /etc/cloudflared/config.yml tunnel run
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
