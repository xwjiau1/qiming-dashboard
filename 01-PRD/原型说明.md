# 启明科技 — 公司管理平台原型说明

**版本：** v1.0 MVP
**日期：** 2026-06-11
**撰写人：** Mery（CIO）
**技术栈：** React + Vite + Tailwind CSS + shadcn/ui + GSAP + Framer Motion + anime.js

---

## 一、页面清单与路由对应

| 路由 | 页面组件 | 布局 | 页面标题 | 副标题 |
|------|---------|------|---------|--------|
| `/` | `Dashboard.tsx` | `PageLayout` | 总览 | 启明科技 · 管理驾驶舱 |
| `/departments` | `Departments.tsx` | `PageLayout` | 部门与智能体 | 管理组织架构，了解你的 AI 智能体团队 |
| `/projects` | `Projects.tsx` | `PageLayout` | 项目管理 | 公司级项目管理，跨部门协作 |
| `/documents` | `Documents.tsx` | `PageLayout` | 文档中心 | 统一管理公司知识资产 |
| `/tasks` | `Tasks.tsx` | `PageLayout` | 任务管理 | 追踪任务进度，任务与项目关联 |

### 路由切换动画

全局路由切换由 `App.tsx` 中的 `AnimatePresence` 包裹，配合 `PageLayout` 的 `motion.div` 实现页面切换动画：
- **入场：** opacity: 0 → 1, y: 8px → 0, duration: 300ms, ease: `[0.33, 1, 0.68, 1]`
- **离场：** opacity: 1 → 0, y: 0 → -8px, duration: 200ms

## 二、每个页面的核心功能描述

### 1. 总览页面（Dashboard）

**核心定位：** 管理驾驶舱，一页看全全局状态。

**布局结构（从上至下）：**

```
Hero 区域（GalaxyCanvas 背景 + 标题 + 按钮）
  └── GalaxyCanvas 粒子系统（Canvas 全屏）
  └── SplitTextReveal 标题动画（逐字 3D 入场）
  └── 新建项目/新建任务按钮

KPI 卡片区（4 列网格）
  └── 项目总数 | 进行中 | 已完成 | 待处理
  └── 每个卡片含：图标 + 数字（滚动动画）+ 趋势标签

部门状态 + 最近动态（5 列网格）
  └── 部门状态（3列）
  │     └── 技术部卡片：成员数、负责人、任务统计、参与项目标签
  │     └── 设计部卡片：同上
  └── 最近动态（2列）
        └── 时间线：6 条活动记录，带纵向连接线

项目概览（3列网格）
  └── 非已完成项目的前 3 个
  └── 每个卡片：状态标签 + 部门标签 + 名称 + 描述 + 里程碑条 + 进度条 + 协作头像 + 截止日期

待办任务 + 任务统计（2列网格）
  └── 待办任务：5 个活跃任务列表（hover 高亮）
  └── 任务统计：SVG 环形图（已完成/进行中/待处理三段）+ 图例
```

**页面特有功能：**
- **GalaxyCanvas 粒子背景：** 吸积盘粒子系统（1400 粒子），鼠标靠近时粒子变亮
- **SplitTextReveal 标题动画：** 标题文字逐字符 3D 旋转入场（rotateX: -70°）
- **数字滚动动画：** KPI 卡片数字从 0 递增到目标值，duration: 2s
- **点击项目卡片** → 打开 `ProjectDetailModal` 模态框

### 2. 部门页面（Departments）

**核心定位：** 组织架构和智能体档案展示，帮助新成员快速了解团队。

**布局结构：**

```
页面标题区
  └── 标题：「你的智能体团队」+ Sparkles 图标
  └── 描述：每个智能体都有独特的身份背景和能力

部门卡片（垂直堆叠，每个部门独立卡片）
  └── 部门头部
  │     └── 渐变图标（Code=蓝色, Palette=金色）+ 名称 + 标签 + 成员数 + 描述
  └── 智能体核心卡片（内嵌）
  │     └── 头像区：头像（hover 放大）+ 在线脉冲指示器 + 徽章
  │     └── 信息区：名字（渐变文字）+ 职位 + 故事（展开/收起）+ 能力标签
  └── 负责项目列表
        └── 该部门参与的项目，含进度条和状态标签
```

**页面特有功能：**
- **故事展开/收起：** 点击「展开完整故事」/「收起故事」，Framer Motion `AnimatePresence` 高度动画展开
- **头像 hover：** `scale: 1.03`，带部门主题色发光阴影（box-shadow）
- **能力标签：** 胶囊形状，带边框色，点击无交互（纯展示）

---

### 3. 项目页面（Projects）

**核心定位：** 公司级项目列表，支持筛选、搜索、查看详情。

**布局结构：**

```
筛选工具栏（flex 布局）
  └── 状态筛选按钮组（全部/进行中/已完成/规划中）
  └── 搜索框（带 Search 图标）
  └── 排序按钮
  └── 新建项目按钮（蓝色主按钮）

项目卡片网格（2列，响应式）
  └── 每个项目卡片：
        └── 状态标签 + 参与部门标签（最多2个，超出显示 +N）
        └── 项目名称 + 描述（2行截断）
        └── 项目周期迷你条：里程碑进度条，显示当前阶段
        └── 任务进度：已完成/总数 + 百分比 + 渐变进度条
        └── 底部：协作头像堆叠（-space-x-2）+ 截止日期 + 更新时间
```

**页面特有功能：**
- **状态筛选：** 按钮组激活态为蓝色背景，切换时实时过滤项目列表
- **搜索过滤：** 实时匹配项目名称（不区分大小写）
- **空状态：** 无匹配项目时显示 FolderKanban 浮动图标 + 清除筛选按钮
- **点击卡片：** 打开 `ProjectDetailModal`（模态框详细说明见「关键交互」章节）
- **进度条动画：** 从 0% 动画到目标进度，duration: 800ms，delay 按索引递增

### 4. 文档页面（Documents）

**核心定位：** 知识资产管理，按类型快速查找文档。

**布局结构：**

```
搜索 + 上传区
  └── 搜索框（带 Search 图标）
  └── 上传文档按钮（蓝色主按钮）

类型筛选（flex wrap）
  └── 6 个类型按钮：全部/技术文档/设计文档/产品文档/会议记录/架构方案
  └── 每个按钮含图标，激活态为蓝色背景

文档列表（卡片容器）
  └── 表头：图标列 | 名称 | 类型 | 部门 | 更新者 | 时间 | 状态 | 操作
  └── 文档行（循环渲染）
        └── 类型图标（动态颜色）
        └── 文档名称（hover 变蓝）
        └── 类型标签（响应式隐藏：sm 以下隐藏）
        └── 部门标签（响应式隐藏：md 以下隐藏）
        └── 更新者头像+名字（响应式隐藏：lg 以下隐藏）
        └── 更新时间（响应式隐藏：sm 以下隐藏）
        └── 状态标签（最新/待更新/草稿）
        └── 操作按钮：查看 + 下载（hover 显示）

空状态：FileText 浮动图标 + 提示文字
```

**页面特有功能：**
- **类型筛选：** 按钮组切换，带 `AnimatePresence` 切换动画（列表淡入淡出）
- **hover 操作：** 鼠标悬停行时显示查看和下载按钮，移开时隐藏
- **响应式隐藏：** 小屏幕下逐步隐藏列，保证核心信息可见

### 5. 任务页面（Tasks）

**核心定位：** 任务追踪与看板管理，双视图切换。

**布局结构：**

```
工具栏（flex 布局）
  └── 视图切换（看板/列表）
  └── 项目筛选下拉框（全部项目 + 各项目选项）
  └── 优先级筛选下拉框（全部/高/中/低）
  └── 新建任务按钮（蓝色主按钮）

看板视图（4列网格，响应式）
  └── 待处理列 | 进行中列 | 待审核列 | 已完成列
  └── 每列：
        └── 列头：颜色圆点 + 列名 + 任务计数徽章
        └── 任务卡片（垂直堆叠）

列表视图（卡片容器）
  └── 表头：拖拽 | 复选框 | 任务名/项目 | 优先级 | 部门 | 状态 | 负责人 | 截止
  └── 任务行（循环渲染）
        └── 拖拽手柄（GripVertical）
        └── 复选框（已完成时填充绿色）
        └── 任务名（已完成时划线变灰）
        └── 项目标签（FolderKanban 图标）
        └── 优先级标签（颜色胶囊）
        └── 部门标签（带左边框）
        └── 状态标签（颜色胶囊）
        └── 负责人头像+名字（响应式隐藏）
        └── 截止日期（响应式隐藏）

空状态：CheckSquare 浮动图标 + 提示文字
```

**页面特有功能：**
- **看板/列表切换：** 按钮组切换，带 `AnimatePresence` 淡入淡出动画
- **任务卡片 hover：** `y: -2` 上浮 + 边框高亮（border-brand-blue/20）
- **已完成任务：** 文字划线（line-through）+ 变灰
- **优先级彩色条：** 卡片顶部显示彩色渐变条（红/黄/灰）
- **筛选联动：** 项目筛选和优先级筛选同时生效，AND 逻辑

## 三、关键交互说明

### 3.1 项目详情模态框（ProjectDetailModal）

**触发方式：** 点击 Dashboard 或 Projects 页面的项目卡片。

**结构：**

```
遮罩层（黑色 70% + 毛玻璃 backdrop-blur）
  └── 模态框容器（max-w-5xl, 圆角 2xl）
        └── 头部区域（border-b）
        │     └── 项目名称 + 状态标签 + 描述 + 元信息 + 进度条
        │     └── 关闭按钮（X 图标）
        └── Tab 导航区（border-b）
        │     └── 项目看板 | 周期设置 | 协作流程（带图标 + 下划线激活态）
        └── 内容区域（max-h-[60vh], overflow-y-auto）
              └── Tab 1: 项目看板（4 列看板，该项目下的任务）
              └── Tab 2: 周期设置（时间线 + 里程碑卡片）
              └── Tab 3: 协作流程（可拖拽排序的智能体列表）
```

**入场动画（GSAP Timeline）：**

```
Timeline 顺序：
1. 遮罩层淡入（opacity: 0 → 1, duration: 250ms, ease: power2.out）
2. 内容区缩放滑入（y: 30, scale: 0.96, opacity: 0 → 1, duration: 350ms, ease: back.out(1.2)）
3. 头部内容交错入场（y: 12, opacity: 0, stagger: 0.04, duration: 300ms）
4. Tab 按钮交错入场（y: 8, opacity: 0, stagger: 0.03, duration: 250ms）
```

**Tab 内容切换：** 使用 `AnimatePresence mode="wait"`，内容淡入淡出，duration: 200ms。

**各 Tab 详细说明：**

#### Tab 1: 项目看板（ProjectBoard）
- 4 列看板（待处理/进行中/待审核/已完成），与任务页面看板一致
- 任务卡片入场动画：GSAP `y: 12, opacity: 0, stagger: 0.04, duration: 350ms`

#### Tab 2: 周期设置（ProjectCycles）
- **时间线条：** 横向显示所有里程碑，已完成段绿色，进行中段渐变（绿→蓝），待开始段暗色
- **里程碑卡片：** 序号 + 名称 + 状态标签 + 描述 + 日期范围
- 卡片入场动画：GSAP `y: 16, opacity: 0, stagger: 0.06, duration: 400ms`

#### Tab 3: 协作流程（ProjectWorkflow）
- **智能体列表：** 每个节点显示序号、拖拽手柄、头像、名字、部门、角色、职责输入框
- **拖拽排序：** 支持 HTML5 原生拖拽（drag/drop），拖拽时节点 opacity: 0.5，边框虚线
- **上下移动按钮：** ArrowUp/ArrowDown 调整顺序，边界判断（首尾禁用）
- **删除按钮：** Trash2 图标，点击删除节点
- **添加智能体：** 点击「添加智能体」展开可用智能体列表（过滤已添加的），点击后追加
- **职责输入：** 可编辑 input，placeholder「点击输入该节点的协作职责...」

**关闭方式：** 点击遮罩层、点击关闭按钮、ESC 键（未实现，建议后续补充）。

### 3.2 侧边栏交互（Sidebar）

**结构：**

```
Logo 区域（启明科技 + 渐变图标）
导航区域（5 个导航项）
  └── 总览（LayoutDashboard）
  └── 部门（Building2）
  └── 项目（FolderKanban）
  └── 文档（FileText）
  └── 任务（CheckSquare）
用户区域（JiaWen 头像 + 名字 + 角色）
折叠按钮（桌面端显示，移动端隐藏）
```

**交互行为：**

| 场景 | 行为 |
|------|------|
| 桌面端（≥1024px） | 默认展开（240px），可点击折叠按钮切换为收起态（72px），带动画（width: 240px↔72px, duration: 300ms, ease: `[0.65, 0, 0.35, 1]`） |
| 移动端（<1024px） | 默认隐藏（-translate-x-full），点击左上角汉堡按钮展开，带遮罩层（黑色 50%），点击遮罩或导航项后关闭 |
| 导航项激活 | 蓝色背景（bg-brand-blue/12）+ 蓝色文字 + 左侧 3px 蓝色指示条（motion layoutId 动画） |
| 收起态 hover | 显示 tooltip（label 文字），opacity 0 → 1 |
| Logo 文字 | 展开态显示「启明科技」，收起态隐藏（AnimatePresence 淡入淡出） |

---

### 3.3 顶部栏交互（Topbar）

**结构：** 标题（h1）+ 副标题（可选，p）+ 日期 + 搜索按钮 + 通知按钮（带红点）。

**交互：**
- 搜索按钮：点击无实际功能（MVP 中仅展示按钮，后续接入全局搜索）
- 通知按钮：带红色未读圆点（bg-status-error），点击无实际功能（后续接入通知中心）
- 日期：实时显示当前日期和星期

## 四、视觉设计说明

### 4.1 设计理念

**「星际指挥舱」** — 以黑洞吸积盘为视觉隐喻，深蓝黑底色象征宇宙深邃，蓝金色粒子流代表数据流动，整体传达「掌控全局」的沉稳感与科技感。

### 4.2 色彩系统

#### 主色（Brand Colors）

| 颜色 | 色值 | 用途 |
|------|------|------|
| 品牌蓝 | `#0A84FF` | 主交互色、按钮、激活态、链接、技术部主题 |
| 品牌蓝浅 | `#38BDF8` | 悬停态、辅助文字、进度条中段 |
| 品牌蓝深 | `#0051D5` | 按钮按下态、深色强调 |
| 品牌金 | `#D4A574` | 辅助色、装饰、设计部主题、渐变终点 |
| 品牌金浅 | `#F0C674` | 悬停态、高亮文字 |
| 品牌金深 | `#A67B51` | 深色强调 |

#### 状态色（Status Colors）

| 颜色 | 色值 | 用途 |
|------|------|------|
| 成功绿 | `#30D158` | 完成态、正向指标、里程碑已完成 |
| 警告黄 | `#FFD60A` | 待处理、警告、低优先级 |
| 错误红 | `#FF453A` | 错误、高优先级、暂停状态 |

#### 表面色（Surface Colors）— 深色层级

| 颜色 | 色值 | 用途 |
|------|------|------|
| 表面主色 | `#0C0C0E` | 卡片背景、容器背景 |
| 表面次色 | `#141418` | 次要背景、hover 背景、输入框背景 |
| 表面三级 | `#1E1E24` | 边框、分割线、表头背景 |

#### 文字色

| 颜色 | 色值 | 用途 |
|------|------|------|
| 白色 | `#FFFFFF` | 主标题、重要文字 |
| 灰 300 | `#D1D5DB` | 正文、次要标题 |
| 灰 400 | `#9CA3AF` | 描述文字、辅助信息 |
| 灰 500 | `#6B7280` | 时间戳、极次要信息 |

### 4.4 粒子效果（GalaxyCanvas）

**技术实现：** Canvas 2D + anime.js 驱动，requestAnimationFrame 循环渲染。

**视觉效果：**
- **1400 个粒子** 沿椭圆轨道向内螺旋运动，模拟黑洞吸积盘
- **颜色分层：** 内层白/蓝白 → 中层金/橙 → 外层暗红
- **爱因斯坦环：** 事件视界边缘（42px 半径）有极亮光环折射
- **鼠标交互：** 鼠标靠近 120px 范围内粒子亮度增加
- **背景：** 200 颗微弱星星，深蓝黑底色（#020205）+ 径向暗晕
- **性能：** 使用 `globalCompositeOperation: 'screen'` 实现发光叠加

**渲染管线：**
```
1. 清空画布 → 填充背景色 #020205
2. 绘制径向暗晕（中心亮，边缘暗）
3. 绘制 200 颗星星（随机位置、大小、透明度）
4. 更新粒子位置（angle += speed, radius -= 0.02）
5. 按距离计算颜色（内→外：白→金→暗红）
6. 绘制粒子发光（径向渐变）+ 核心（实心圆）
7. 绘制爱因斯坦环（两层径向渐变）
8. 绘制事件视界（纯黑圆）
9. 绘制事件视界边缘折射光
10. 绘制鼠标光晕（可选）
11. requestAnimationFrame 循环
```

### 6.2 数据来源与计算

#### Dashboard 页面数据流

```
总览页面数据源：
├── KPI 卡片（4个）
│   ├── 项目总数: kpiData.totalProjects (5)
│   ├── 进行中: kpiData.inProgress (3)
│   ├── 已完成: kpiData.completed (1)
│   └── 待处理: kpiData.pending (1)
│   └── kpiData 由 projects 数组实时计算得出
│
├── 部门卡片（2个）
│   ├── 数据源: departments 数组
│   ├── 任务统计: tasks.filter(t => t.department === dept.name)
│   └── 参与项目: projects.filter(p => p.involvedDepartments.includes(dept.name))
│
├── 最近动态
│   └── 数据源: activities 数组（取前 6 条）
│
├── 项目概览（3个）
│   └── 数据源: projects.filter(p => p.status !== 'completed').slice(0, 3)
│
├── 待办任务（5个）
│   └── 数据源: tasks.filter(t => t.status !== 'completed').slice(0, 5)
│
└── 任务统计（环形图）
    ├── 总数: kpiData.totalTasks
    ├── 已完成: kpiData.completedTasks
    ├── 进行中: kpiData.inProgressTasks
    └── 待处理: kpiData.pendingTasks
```

#### Departments 页面数据流

```
部门页面数据源：
├── 部门卡片（垂直排列）
│   ├── 数据源: departments 数组
│   ├── 部门头部: name, shortName, description, memberCount, color
│   ├── 智能体信息: head (Agent 对象) → avatar, name, title, story, abilities, status
│   └── 负责项目: projects.filter(p => p.involvedDepartments.includes(dept.name))
│       └── 每个项目显示: name, status, progress
```

#### Projects 页面数据流

```
项目页面数据源：
├── 筛选状态
│   ├── activeFilter: 'all' | 'in-progress' | 'completed' | 'planning'（useState）
│   └── searchQuery: string（useState）
│
├── 过滤逻辑（useMemo）
│   ├── 状态过滤: if (activeFilter !== 'all' && p.status !== activeFilter) return false
│   └── 搜索过滤: if (searchQuery && !p.name.toLowerCase().includes(searchQuery.toLowerCase())) return false
│
├── 渲染列表
│   └── filteredProjects.map((project, index) => <ProjectCard />)
│
└── 项目详情模态框
    ├── 触发: onClick={() => setSelectedProject(project)}
    ├── 传递数据: project（完整 Project 对象） + tasks（全部任务数组，内部过滤）
    └── 关闭: onClose={() => setSelectedProject(null)}
```

#### Documents 页面数据流

```
文档页面数据源：
├── 筛选状态
│   ├── activeFilter: 'all' | 'technical' | 'design' | 'product' | 'meeting' | 'architecture'
│   └── searchQuery: string
│
├── 过滤逻辑
│   ├── 类型过滤: if (activeFilter !== 'all' && d.type !== activeFilter) return false
│   └── 搜索过滤: if (searchQuery && !d.name.toLowerCase().includes(searchQuery.toLowerCase())) return false

    ├── 类型图标: typeIconMap[doc.type]（lucide-react 图标）

```

#### Tasks 页面数据流

```
任务页面数据源：

│   ├── viewMode: 'board' | 'list'（useState）

│   └── priorityFilter: string（useState，默认 'all'）

│   ├── 4 列定义: columns 数组（todo, in-progress, review, completed）
│   └── 每列任务: filteredTasks.filter(t => t.status === col.key)

│
└── UI 映射
    ├── 优先级: priorityConfig[task.priority]（高=红, 中=黄, 低=灰）
```

### 7.3 已知限制与后续优化

| 限制 | 说明 | 优先级 |
|------|------|--------|
| 无后端 | 所有数据为静态 Mock，状态不持久化 | P1 |
| 无身份验证 | 无登录/权限控制，所有用户看到相同内容 | P1 |
| 新建功能未实现 | 新建项目/任务/文档按钮仅展示，无实际表单 | P1 |
| 搜索仅前端过滤 | 无后端搜索能力，数据量大时性能下降 | P1 |
| 文档无真实文件 | 上传/下载按钮无实际功能 | P1 |
| 协作流程无持久化 | 拖拽调整顺序刷新后重置 | P1 |
| 无任务状态拖拽 | 看板中无法拖拽任务跨列移动 | P1 |
| 粒子系统性能 | 低端设备可能掉帧，需考虑降级或可选关闭 | P2 |
| 无通知系统 | 铃铛按钮无实际功能 | P2 |
| 无日历视图 | 里程碑和截止日未以日历形式展示 | P2 |
| 无数据导出 | 无法导出报告或统计 | P2 |
