## 修复记录

### 修复 1: 动态 API 字段名驼峰化

**问题**: 动态 API 返回的字段名使用下划线命名（如 `user_name`），与前端期望的驼峰命名（`userName`）不一致。

**修复文件**: `src/backend/routes/动态.ts`

**修复内容**: 在路由中将所有数据库下划线字段名转换为驼峰命名：

```typescript
const data = rows.map((row) => ({
  id: row.id,
  userId: row.user_id,
  userName: row.user_name,
  userAvatar: row.user_avatar,
  action: row.action,
  target: row.target,
  targetId: row.target_id,
  targetType: row.target_type,
  timestamp: row.timestamp,
  color: row.color,
  createdAt: row.created_at,
}));
```

**验证**: 测试 8.3 通过，字段名正确。
